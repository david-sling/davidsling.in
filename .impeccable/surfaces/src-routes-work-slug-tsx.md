# Project case-study pages (/work/$slug)

Scope: one route rendering three case studies (Wave, Equanim, offlyn.love). Mode: Experience inside the established landing-page world; DESIGN.md not yet written, the world lives in code (src/styles.css tokens, rounded sheets, General Sans, per-project colour fields).

Audience and job: developer peers arriving by deep link from GitHub, LinkedIn or a post. They want the story, the mechanism and the judgement calls, fast, and a way to try the thing.

Content truth: Wave story from David's LinkedIn post (Mac + Windows laptops, Claude Code on each, copy-pasting schemas between them). Wave/Equanim facts from their public repos. offlyn.love facts from David's public blog post and approved product images only; never its private source. Name is always "offlyn.love".

## Direction contract

THESIS: one shared case-study frame, with exactly one signature element per project drawn from what the product does. Refuses the category default of a long image gallery with identical sections and a metrics hero.

OWN-WORLD: the landing page's world unchanged: ground/sheet tokens, 40px rounded sheets, General Sans, blue accent; each page owns its project colour field (wave yellow, equanim cyan, offlyn pink) for the hero and its signature block only.

STORY: why it exists, how it works, the decisions that mattered, how it was built with agents, then a door to the next project.

FIRST VIEWPORT: project colour sheet, name large at left with one-line summary, role/date/stack facts and Live/Source buttons; product media at right (Wave video, live Equanim pendulum, offlyn.love match art). Stacked on mobile.

FORM: user-chosen structure (shared frame + option 1 signatures: Wave "joined" section dividers, Equanim spec-beside-render with hover highlighting, offlyn.love hidden-mutual-friend reveal). seed: none (direction specified by the user; no roll)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
